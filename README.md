# HR Employee Attrition Analysis

**Tools:** Power BI | DAX | Power Query

## Objectives
- Analyze attrition count and percentage.
- Identify employee-reported reasons for leaving.
- Determine which experience category has the highest attrition.

## Key Measures
- Attrition Count
- Attrition Percentage
- Total Employees

- Power BI dashboard
- Dataset (subject to sharing permission)
